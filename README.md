# Barbershop Website 💈

A fictional barbershop website created as a personal practice project to explore and improve my front-end web development skills.

The website features a modern, light-dark design with gold accents, responsive layouts, service sections, a barber team section, a photo gallery, and an appointment booking interface.

> **Disclaimer:** This is a fictional project created for educational and portfolio purposes only. It does not represent a real business/barbershop. All business details, contacts and services are illustrative.

## Features

* **Responsive Design** — Layout adapted for desktop, tablet, and mobile devices.
* **Modern UI** — Light-Dark theme with gold accents and subtle visual effects.
* **Services Section** — Service cards with interactive category filtering.
* **About Section** — Introduction and statistics for the fictional barbershop.
* **Barber Team** — A section showcasing fictional team members.
* **Gallery** — A visual showcase of barbershop-style images.
* **Appointment Form** — Interactive booking form with service, barber, date, and time selection.
* **Mobile Navigation** — Responsive navigation menu for smaller screens.
* **Scroll Effects** — Navigation styling and reveal animations triggered by scrolling.

## Built With

* HTML5
* CSS3
* JavaScript
